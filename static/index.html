    PROYECTO ACADÉMICO

    Acerca del proyecto

    Un laboratorio para explorar geometría tridimensional y diseño orientado a objetos.

    3D

    SISTEMA AVANZADO DE FIGURAS 3D

    Un mismo contrato. Tres sólidos. Cálculos especializados.

    La aplicación conserva el modelo matemático en Python. Una clase abstracta define el contrato de las figuras y cada subclase implementa sus propiedades y fórmulas. La interfaz web consume los resultados a través de una API local.

    01

    Abstracción

    Figura3D define los métodos y dimensiones que debe ofrecer toda figura.

    02

    Herencia

    Cubo, Esfera y Cilindro extienden el contrato común.

    03

    Polimorfismo

    obtener_resultados() recorre la colección sin preguntar qué clase concreta procesa.

    04

    Escalado

    El área se multiplica por s² y el volumen por s³, sin modificar dimensiones ni crear instancias.

    FÓRMULAS DEL MODELO

    CuboA = 6l²V = l³
    EsferaA = 4πr²V = ⁴⁄₃πr³
    CilindroA = 2πr(r + h)V = πr²h
